# v0.9 fabrication files

The [files directory](files/) contains the KiCad 10.0.8 Gerber X2 and metric Excellon outputs for the v0.9 corrected prototype. The set includes front and back copper, solder mask, and silkscreen, the Edge.Cuts profile, the Gerber job file, and separate plated and non-plated drill files. The NPTH file has zero drill hits.

Upload the contents of `files/` at the root of the fabrication ZIP. The Edge.Cuts centerline defines the 24 × 41 mm profile. The design is two-layer FR-4, 1.6 mm thick, with the original 1 oz copper prototype specification. See [assembly and test](../../docs/ASSEMBLY.md) and [prototype status](../../docs/KNOWN_ISSUES.md).
